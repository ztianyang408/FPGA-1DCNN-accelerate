# Vitis Board Application

`src/helloworld.c` is the ARM-side demonstration application. It initializes the CNN IP, GPIO, OLED and UART, writes the 512-dimensional test vector to DDR, starts the CNN accelerator, reads the result and displays the status.

The BSP headers such as `xparameters.h`, `xgpio.h` and the generated CNN driver are intentionally not stored here. They are generated by Vitis from the matching XSA in `../release/`.

Recommended flow:

1. Create or update a Vitis platform from `../release/cnn1d_wrapperv4oled1.8v.xsa`.
2. Create a standalone domain for `ps7_cortexa9_0`.
3. Create an application project and add the files under `src/`.
4. Build the application.
5. Program the board with the matching `cnn1d_wrapperv4oled1.8v.bit`.
6. Launch on hardware and monitor UART.
